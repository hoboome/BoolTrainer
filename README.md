# BoolTrainer

Учебный тренажёр по булевым функциям на Python и PySide6.

## Установка

```
git clone https://github.com/hoboome/BoolTrainer.git
cd BoolTrainer
pip install -r requirements.txt
python main.py
```

## Тесты

```
pytest
```

## Лицензия

MIT

## Возможности
- Ввод выражения с операциями NOT, AND, OR, XOR, IMPL, EQV, NOR, NAND
- Таблица истинности, СДНФ, СКНФ
- Минимизация методом Куайна — Мак-Класки
- Карта Карно для 2–4 переменных с подсветкой групп
- Экспорт таблицы в PNG
- Тренажёр: теория и случайные задания с автопроверкой
